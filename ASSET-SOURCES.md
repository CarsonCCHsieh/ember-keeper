# Artwork provenance

All files in `assets/` were created for Ember Keeper by the local authoring helper, with CC and OpenAI Codex assistance, as newly authored SVG geometry. They use no external image references, downloaded fonts, script, event handlers, stock photos or copied game artwork.

- `background.svg`: original frame, grid, six-spoke circuit, meters and indicator art.
- `valve-closed.svg`, `valve-open.svg`: original paired valve states.
- `source-ring.svg`, `next-ring.svg`: original incoming/preview indicators, distinguishable by solid dashes versus dots as well as colour.
- `flame.svg`, `flame-hot.svg`, `flame-low.svg`: original flame silhouette and state palettes.
- `energy-fill.svg`, `heat-fill.svg`, `pulse-fill.svg`: original meter geometry.
- `button.svg`, `vent-button.svg`: original button shapes/icons.
- `overlay.svg`, `pause-overlay.svg`: original modal panels.
- `cover.svg`: original competition cover illustration and title composition.

The game text uses the runtime's default system font; no font file is redistributed. These project assets use the repository's MIT licence. GDevelop's runtime and any runtime-provided loading/logo files retain their upstream attribution and licences.
